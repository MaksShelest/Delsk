Delsk · Исследовательская лаборатория

Самостоятельные исследования без запущенной игры и без Godot. Каждый прогон использует общий симулятор Delsk; исходные настройки игры не меняются.

1. Выберите исследование

Seed определяет воспроизводимый опыт. Для сравнения вариантов используются одинаковые seed. Новый независимый seed полезнее повтора того же опыта.

Изменяемые параметры — добавить свой фактор

Несколько значений создают сравниваемые варианты. Для денег и зарплат единица здесь — сотая монеты. true / false означают включено / выключено.

Дополнительно: повторы, профили, LLM, JSON

Для гибрида нужны установленная модель, работающий Ollama и явный modelConfig внутри репозитория/лаборатории. Доступность модели не гарантируется проверкой JSON. Повторы одного алгоритмического seed — реплики, не независимая выборка.

Здесь можно менять economy/controllers, composition и диапазоны факторов. Seed, тики, повторы и режим берутся из полей выше. Для полного uint64 seed используйте CLI JSON.

Все комбинации сначала проверяются общими валидаторами. Нажатие запускает также ранее ожидающие задания очереди.

3. Результаты и сравнение


Готовые результаты последней серии появятся здесь автоматически. Можно отметить несколько серий и сравнить их. Денежные показатели ниже переведены в монеты; исходные JSON/CSV сохраняют сотые монеты.




Сравнивайте одинаковые сценарии/профили, различающиеся объявленными факторами. Парные разности сопоставляют одинаковые seed/повторы. Короткая проверка не доказывает баланс или превосходство Hard. Операционный денежный результат не равен бухгалтерской чистой прибыли.




Как работать и где сохраняются данные

  1. Выберите «Быстрая проверка» и нажмите «Начать исследование».
  2. Дождитесь завершения. Все варианты и seed выполняются последовательно.
  3. Нажмите «Скачать серию ZIP» рядом с серией: внутри план, проверенные настройки, исходные результаты и сводки.
  4. Для нового исследования выберите другой готовый вариант или добавьте параметр. Пауза действует между прогонами.
  5. Повторное открытие ResearchLab.cmd открывает ту же очередь. После перезапуска завершённые опыты сохраняются, продолжение требует кнопки «Продолжить».


Это локальные исследовательские выгрузки с полной приватной историей. Храните их локально. Закрытие вкладки не останавливает очередь; для завершения используйте кнопку ниже. Активный ограниченный прогон закончится перед выходом.
