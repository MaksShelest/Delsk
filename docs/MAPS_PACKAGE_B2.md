# Две карты пакета B2

Автор: Шелестов Максим Евгеньевич.

В обычном меню доступны «Речные кварталы · A2»64×48 и «Большой округ · A2»128×96.
Они выбирают явный совместимый `config/vnext/economy.b1-supported.json`;
остальные пять карт сохраняют прежний economy-v6. Можно выбрать3–10ботов,
сложность и прежний необязательный Hybrid. Continue использует сохранённую карту
и состав. Название «Речные кварталы» не означает наличие новой реки/мостов.

Восемь ресурсов: древесина, зерно, камень, железная/медная руда, песок, свёкла,
молочное сырьё. Публичная точка каждого района доступна без оплаты: дойдите,
начните добычу, принесите товар к терминалу и продайте обычным способом. Частные
клетки требуют прежней покупки/аренды. Рыночный спрос конечен, товар не выдаётся
за открытие экрана. Новые производственные отрасли и оборудование не добавлены.

Ратуша: южный подход открывает город/существующие выборные команды. Терминал:
южный грузовой подход открывает обычную биржу. У автосалона — справка с паузой
о будущем магазине пакета E, без покупки/выдачи машин.15мест под лавки доступны
через прежние правила. Коридоры и городские территории покупать/застраивать
нельзя; дорожные вклады/налоги ещё не работают. В3D нет постоянных промышленных
столбиков/цветной сетки; контуры видны в preview и2Dкарте.

Лаборатория: выберите новую карту, совместимый профиль подставится в форму.
Для быстрого опыта:30–120тиков, seed42, алгоритмы, один прогон. Откройте запись
мира/журнал/исходный manifest. Это исследовательский explicit состав/профиль,
а не скрытая подмена обычного B1 setup. Экономические изменения полного A2
профиля должны соответствовать его provenance-контракту; совместимость не
означает, что все будущие отрасли исполняются. Legacy карты/research до15ботов
сохранены; новые карты имеют source max11участников.

CLI использует тот же C# adapter и resolver:

```json
{"npcCount":10,"difficulty":"Medium","seed":42}
```

```bash
dotnet src/Research.Runner/bin/Release/net10.0/Research.Runner.dll --scenario docs/vnext/maps/large_districts.json --economy config/vnext/economy.b1-supported.json --new-game /tmp/new-game.json --script baseline --human-ballot self --ticks 180 --output /tmp/delsk-large
```

Для лаборатории/embedded client сохранены воспроизводимые runtime snapshots
`scenarios/vnext/{small-river,large-districts}.json`. Генерация C#, без мира:

```bash
dotnet src/Research.Runner/bin/Release/net10.0/Research.Runner.dll --export-map-design docs/vnext/maps/small_river.json --economy config/vnext/economy.b1-supported.json --output /tmp/resolved-small
python scripts/check_map_designs.py --output /tmp/map-source-check
```

Экспорт пишет scenario.json только в новую/пустую папку. Исходные design JSON
не переписаны. Различайте SHA точных source bytes, SHA snapshot bytes, SHA
профиля и runtime ConfigHash после выбора состава/seed. Layout version
`map-adapter-1` сохраняет исходные строковые ID/клетки/дороги/контуры/районы/
парковку; числовые Plot IDs стабильно следуют порядку промышленных клеток и лавок.
Civic source не содержит entry, а terminal/dealer не содержат building:
адаптер явно трактует южный ряд как подход, terminal north2×2 как корпус;
dealer north5×3 — корпус, два южных ряда — parking/apron; ратуша использует
точный source2×2building. Сам source footprint не изменяется. Эти правила
версионированы и проверены настоящими runtime путями, а не дорисованы в SVG.

Save хранит resolved layout/rules/roster/controllers. Изменение исходного JSON
после начала партии не меняет сохранённый мир. Не редактируйте начатые saves;
при правке дизайна заново экспортируйте snapshots и запускайте source/runtime
checks. Новые дороги/стройка/производства относятся к следующим пакетам.
