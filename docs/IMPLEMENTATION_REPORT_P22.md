Автор: Шелестов Максим Евгеньевич. Дата: 16.10.2026.

База —900b8d4, актуальный merge PR19; рабочее дерево было чистым. В фактическом коде существовали P00–P21, immutable controller observation, алгоритмические планы, общий Hosting barrier, checkpoint epoch и recorded command replay. Agents.Llm/adapter/decision slots отсутствовали. Новая ветка feat/local-model-adapter-p22 использует существующие механизмы, не создаёт второй валидатор или экономический движок.

## Реализация

Agents.Llm зависит только от Core/Algorithmic. ILocalModelAdapter имеет одну асинхронную операцию. OllamaAdapter вызывает только loopback `/api/chat`, stream=false, JSON schema, ограниченный ответ и параметры контекста/генерации. Credentials/неожиданные URL/redirect/неверный envelope/переполнение body/HTTP failure отклоняются. Ошибки не возвращают raw server debug. Авторитетный Core не получает HTTP, wall clock или Task.

Модель выбирает optionId из до4 разных целей существующего utility плюс Hold. ModelOptions — чистое чтение без PRNG/резерва/изменения плана. Команды, количества, цены и подпись остаются точными неизменяемыми частями доверенного плана; свободный JSON не может дописать деньги/actor/quantity. Parser требует ровно6полей без duplicate/unknown keys, целую identity и listed option; запрещает oversized/control/text wrappers. После проверки на apply барьере применяется прежний AlgorithmicController executor и обычный Send/Core validator.

RelevantVersion охватывает собственное/двустороннее состояние и условия реально использованных публичных предложений/участков/выборов. Изменившиеся цена/срок/ресурсы не исправляются догадкой; нерелевантная добыча другого участника не мешает. Никакого world hash/seed/private market PRNG/будущих цен/третьесторонних support terms в запросе нет. Prompt строится по allowlist, ограничен16KiB; собственная память содержит только доверенный итог своей цели, raw reason модели туда не копируется.

Один общий runtime: одна физическая инференция, очередь3, максимум один pending request/actor. Заявки принимаются целым барьером с tick-ротацией, а не постоянным первым ID. Ответы также замораживаются до всех Decide. HTTP/Task работает на отдельном worker; даже синхронно блокирующий или игнорирующий cancellation адаптер не блокирует Step. Истёкший запрос не разрешает параллельно начать вторую физическую инференцию; остальные слоты используют fallback.

Default: minimum interval30ticks, applyDelay15, TTL15, до4запросов/120ticks, timeout4000ms, retries0. Минимальный applyDelay2 обеспечивает отдельный барьер для асинхронного ответа. Trigger объединяет изменение цели, собственные новые предложения, значительное изменение опубликованной цены и отказы; мелкий шум не вызывает запрос каждый tick. Ранее начатая физическая работа движется в Core. Уже исполняемые планы, поставочные обязательства/оплаченный pickup и короткий auction bid не задерживаются моделью. Новый ещё не отправленный план может ждать до фиксированного applyTick; он снимается из executor и заново оценивается на applyTick, чтобы не сохранить дубликат remote action. Если новое обязательство появилось при ожидании, алгоритм исполняет его параллельно логическому slot. Быстрый ответ не получает дополнительного хода. Invalid/timeout/late/full queue/unavailable/stale → один fallback; если алгоритму сейчас нечего законно выполнить, записывается Hold.

## Сохранение и replay

HybridState v1 сохраняет baseline checkpoint2, plan/cursor/pending commands, logical Pending/Ready slot, frozen request/options/relevant versions/reply, next decision number, cooldown/budget/память и число разрешений. Task/HTTP/внешняя runtime очередь не сериализуются. Hosting даёт существующую sessionEpoch; восстановленный незавершённый slot (включая Ready, ещё не применённый) получает Interrupted и fallback в прежний applyTick. Запрос заново не отправляется, старый callback не проходит epoch/mailbox checks. После уже разрешённого slot план/trace продолжаются точно без новой инференции.

Core World12/Rules baseline-1, Hosting Session2/Envelope1 и существующий utility-economy-v2 не изменены: авторитетные игровые правила прежние. Новая версия контроллера hybrid-plan-v1/checkpoint1. Небольшие lifecycle hooks существующего IController позволяют Binding/Begin/End общего барьера, Hosting не зависит от Agents.Llm. Optional ModelTrace не меняет сериализацию старых controller turns при null. model-decisions.jsonl — полный private researcher trace, публичный поток Core его не получает.

Recorded command replay использует уже зафиксированные разрешения через обычную ленту команд, не спрашивает модель повторно. Точная воспроизводимость живой LLM по одному seed не обещается. `Realtime`, `LiveHeadlessStress`, `ControlledFakeS7` помечаются отдельно. Модель выключена по умолчанию; `--script hybrid --model-mode off` выполняет прежний baseline без запросов. Реальная модель включается только явным --model-mode ollama/--model-config.
