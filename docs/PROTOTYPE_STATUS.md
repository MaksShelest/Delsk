## Проверка сейчас

Получить ветку `feat/extraction-equipment-p11`, открыть Delsk.sln в Rider. [Инструкция Windows/Godot/Rider](LOCAL_SETUP.md). После restore/build:

```powershell
dotnet tests/Simulation.Tests/bin/Release/net10.0/Simulation.Tests.dll -noColor -noLogo -parallelMode none
dotnet run --project src/Research.Runner -c Release --no-build -- --scenario scenarios/equipment-cycle.json --script equipment --output artifacts/equipment
```

Ожидается succeeded,200 тиков. Добыто/продано wood16/grain2; payroll250 и закупка/upgrade90000 minor units; cash первого32750, второго85600; население7/unemployed7. Проверить events.jsonl, labor.csv, ledger.jsonl и final-state.json. Buffer автоматической машины не появляется в личном инвентаре до разгрузки; продажа не происходит до пути в терминал. Выгрузка final-state ещё не загружаемый checkpoint.

Для знакомства с производством/землёй использовать `--script development --scenario scenarios/land-and-content.json`; с зарплатами `--script labor --scenario scenarios/labor-dynamics.json`. Разные output каталоги сохранят результаты. Старые короткие regression fixtures намеренно растягивают трудовой шаг; динамику найма смотреть в labor/equipment, а не считать их балансом обычной игры.

Результаты этой итерации и непроверенное перечислены в [отчёте P11](IMPLEMENTATION_REPORT_P11.md). Следующая задача **P12**, затем P13. По окончании P13 обновить эту таблицу и дать команду нового автономного прогона; такой команды сейчас ещё нет.
