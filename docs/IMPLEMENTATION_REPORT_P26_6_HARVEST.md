## Поведение игрока

На клетке ресурса «Добывать» запускает повтор коротких циклов по одной единице обычной длительности. Команда принимается на следующем игровом тике, затем кнопка меняется на «Остановить добычу» с зелёной полосой текущего цикла. Готовая единица появляется в HUD/инвентаре только после завершения. Повтор не требует новых нажатий; заполнение инвентаря останавливает его с пояснением.

Явная остановка исполняется общей командой перед завершением добычи того же тика. WASD позволяет уйти: при фактическом выходе из области ресурса текущий цикл отменяется сразу в Core, его прогресс теряется, вместимость и занятость освобождаются. Уже готовый запас остаётся. Возврат не запускает добычу сам. Переход между соседними клетками того же ресурса сохраняет цикл; движение внутри клетки или упор в стену его не отменяют. Личная работа на добывающей машине требует клетки этой машины.

Меню, Debug и потеря фокуса останавливают весь мир вместе с прогрессом, без catch-up при возвращении. Сохранение/загрузка продолжают активный цикл. Debug сохраняет конечную команду добычи1, добавляет доступную остановку текущей добычи и продвигает общий мир ровно на один тик. Подписи и объяснения доступны RU/EN.

## Core, сохранение и replay

StartHarvesting создаёт PersonalJob.Kind=HarvestLoop с уникальным JobId и собственным hold вместимости на одну единицу; phase4 выдаёт товар и запускает следующий цикл. StopHarvest работает в phase1. Конечные Harvest/EquipmentHarvest остаются доступны алгоритмическим контроллерам; отмена и право движения одинаковы для всех участников. При отмене машинной добычи освобождается также PersonalJobId машины. MoveTo проверяет путь до замены работы движением, поэтому NoPath не уничтожает добычу.

RulesVersion изменена на manual-harvest-1. World schema12/Session2/Envelope1 и policy utility-economy-v2/checkpoint2 прежние: существующих полей SavedJob достаточно для полного состояния повтора. Restore проверяет новый kind, одноединичный объём, длительность, ссылку на принятую собственную команду, capacity hold и его обратное владение. Новых UI-флагов авторитетной добычи нет.

Старые baseline-1 сохранения явно отклоняются без миграции и остаются на прежнем пути; клиент использует отдельный SavePath с новой RulesVersion. Новая партия не перезаписывает прежний файл правил.

Квант свободного движения может отменить добычу между тиками. Только типизированное phase9 событие HarvestCancelled/LeftResourceArea с проверенными ссылками может следовать после TickCommitted; произвольный незавершённый журнал по-прежнему запрещён. Checkpoint сохраняет реальную позицию/квант, освобождённый hold и отмену. Replay проходит тот же квант. Дополнительно исправлено применение WASD, записанного на конечной опубликованной границе replay, включая остановку движения.

HarvestOf — узкий read-only запрос собственной операции. Hosting передаёт его в PlayerView; полоска использует Tick/TravelQuantum только для отображения. Core не читает wall clock, Godot не начисляет товар и не использует чужие private/research данные.
