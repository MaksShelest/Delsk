  пороги600/3000/12000/40000, без отдельного productionCount gate. Производство и
  награда складываются; торговый путь до600XP без производства проверен.
- Два задания по существующим финансируемым договорам,5/15/30партий50/100/200XP,

- Платная начальная стройка60тиков из материалов на собственной ground-клетке70;
  маленький рюкзак позволяет собирать комплект несколькими обычными рейсами.
- Реальные корпуса1/3/4/5/6клеток,1/2/3/4/5мест, вход и выход80/120/160/200/240.
  Земля оплачивается отдельно, материалы расширения только со входа. Цены,
  комплекты и120/180/300/480тиков из BALANCE. До конца старый корпус прежний.
  Все клетки реконструкции получают целевой физический уровень; будущие клетки
  проекта защищены capacityholds от поздней выкладки и потери товара.
- Общая технология не дарит второй фабрике корпус, оборудование или работников.
  Поддержанные рецепты доступны по общей технологии; profile активирует только
  прежние базовые D1рецепты. Новые места оснащаются прежним платным монтажом D1.
- Подготовка к расширению завершает WIP без следующей партии, сохраняет договоры

  staging/покупку земли/проекты теми же командами, с прежними сохраняемыми планами.
- Developer: установить/прибавить отраслевой XP через прежний аудит вмешательств,

## Граница и ограничения

Завершена только механика D2: P65 и физическая часть P66. **Полный производственный
контент, импорт и модернизации V2/V3 оставлены D3 по последнему заданию.** P66
целиком и пакетD целиком не закрываются. В ordinary profile не добавлены бесплатные
материалы. Доступность всех ступеней натуральным развитием текущих цепочек не
заявляется: в геометрических fixtures источники подготовлены, XP явно ускорен;
обычные XP/unit, пороги и торговый способ отдельно проверены без такого ускорения.

Задания не создают новый внешний бюджет и не заменяют исходный договор; отказ
от задания не отменяет обязательство.500XP-проект требует явного финансируемого
публичного источника в config; обычный профиль не выдумывает его автоматически.
Старые сохранения сохраняют прежний профиль, автоматического включения D2 в D1
нет. Полная оптимальная стратегия NPC по всем шести цепочкам, длительный баланс,
Windows EXE и Android/hardware не являются доказанными этими software gates.
Реальная LLM не запускалась. Следующий шаг — отдельное задание D3.
