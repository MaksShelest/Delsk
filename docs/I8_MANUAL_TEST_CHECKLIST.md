# Ручная приёмка DELSK I8 на Windows и Android

Автор — Шелестов Максим Евгеньевич.

Запишите commit из `packages.json`, SHA-256 комплекта, ОС и модель устройства, память,
разрешение, режим моно/гибрид, профиль игры, карту, seed и количество NPC. На каждый
шаг достаточно записать время, результат, последний игровой тик и сообщение или
снимок при отказе. Для сетевого профиля LLM запишите точные версию runtime, модель,
квантование и параметры. Перед проверкой повреждений сделайте внешнюю копию тестовых
миров.

## Сборки и запуск

- Скачайте артефакт Windows или Android из успешного запуска сборок на [PR #112](https://github.com/MaksShelest/Delsk/pull/112/checks). Внутри есть `packages.json` и каталоги `release` и `developer`. Сопоставьте имя, размер и SHA-256 допускаемого файла. На Windows используйте `Get-FileHash -Algorithm SHA256 .\release\DelskProbe.exe`, для APK — `Get-FileHash -Algorithm SHA256 .\release\DelskH3.apk` или `sha256sum`.
- Распакуйте весь Windows комплект, включая каталог `data_Delsk.Client_windows_x86_64` и PCK, когда он идёт отдельным файлом. Запустите `release\DelskProbe.exe` с учётной записью без прав администратора. Повторите из `developer` с изолированными мирами.
- APK предназначен для ARM64 тестового устройства и подписан тестовым ключом. Сверьте package ID и подпись из журнала сборки, затем установите файл через интерфейс устройства или `adb install путь/к/DelskH3.apk`. Используйте тестовое устройство или отдельный пользовательский профиль, если на телефоне есть прежнее сохранение или пакет с другой подписью. Запустите обычную сборку, затем отдельно Developer при необходимости.

## Обычная партия

- [ ] На экране старта выберите Малую долину, seed 17, Medium, 3 NPC и одно направление. Подтвердите 200,00 монет, пустой рюкзак, цель и описание специализации. На Малой долине повторите открытие новой партии для 6 и 10 NPC. В Лесном крае подтвердите 3 NPC.
- [ ] Откройте программу поддержки. Сверьте целевое назначение, остатки, цену участка и состав поставки. Примите один раз. После покупки и загрузки проверьте, что повторное действие отклоняется и деньги не начисляются.
- [ ] Купите участок у дороги, получите материалы на терминале, физически перевезите их, постройте корпус и доведите первый цикл до продажи. Запишите времена первого выпуска, первой выплаты, сумму до и после, зарплату, электричество и расход сырья. Повторите на другой карте и с другой специализацией.
- [ ] Проверьте русскую и английскую локализации. Сверьте цены и зарплаты с учётом разделителя, переносы, маленький экран, длинные названия и доступность основных кнопок. На Windows попробуйте мышь, клавиатуру и колесо. На Android попробуйте перетаскивание, pinch и тап рядом с закрытой панелью.
- [ ] Откройте предприятие, склад, биржу, транспорт, маршруты и параметры труда. При полном складе, отсутствии сырья или недоступной клетке убедитесь, что видна фактическая причина отказа. Проверьте, что одно нажатие создаёт одну команду. Откройте планшет, посмотрите на тик и закройте его.
- [ ] Сохраните тестовый мир с активной перевозкой и партией в WIP. Создайте вторую партию, переименуйте обе и переключитесь через «Мои миры». Проверьте деньги, тик, карту, число NPC, остатки, сотрудники и груз после каждого возврата.
- [ ] Сверните приложение на минуту, вернитесь и проверьте, что прошедшее вне игры время не добавило тиков. Повторите при потере фокуса, штатном закрытии, перезапуске и через «Продолжить». На Android проверьте кнопку «Назад» и возврат из списка последних приложений.
- [ ] В копии каталога тестового мира повредите основной checkpoint. Годный backup должен открыться, соседний мир должен сохранить свои данные. Затем проверьте сообщение при повреждении обеих копий, отмену и подтверждение удаления. Если проверяете принудительное завершение процесса во время записи, используйте только копию каталога и проверьте обе генерации.
- [ ] Из реального позднего сохранения проверьте отдельно расширение, модернизацию, покупку техники, настройку рейса, встречный проезд, дорожные платежи, контракт и выборы. Запишите отдельно, если входное сохранение было подготовлено.

## Платформенные границы

| Проверка | Свидетельство |
|---|---|
| Windows Release и Developer на физическом компьютере | Запуск обеих сборок, по одной обычной партии, повторная загрузка, работа UI на реальном GPU, разрешение и масштаб |
| Android Release на физическом телефоне | Версия Android, архитектура, холодный запуск, touch, сворачивание и восстановление, закрытие, повторное открытие, масштаб и состояние аккумулятора |
| Release / Developer | В Release отсутствует меню Debug. В Developer команда Apply на паузе меняет только выбранное поле; тик, зарплата и штрафы прежние |
| Производительность | На одинаковой карте запишите FPS и задержку в начале и в позднем тестовом мире. Укажите интервал, render backend, разрешение и конфигурацию NPC. Включите отдельно переключение мира и объём RAM |
| Локальная LLM на Windows | Выполните реальное решение через поддерживаемый runtime, затем остановите runtime и подтвердите fallback. Сохраните seed, конфиг, trace решения и replay без повторного inference |

Физические тесты требуют участия владельца. Приёмка остаётся открытой до записи результатов по каждому приложимому пункту. [Отчёт I8](IMPLEMENTATION_REPORT_I8.md)
