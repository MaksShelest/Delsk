# I6-C1 — игровой HUD и нижняя панель действий

Основа: merge I6-B `781f6f10`, ветка `feat/vnext-i6c1-hud-context`. Автор: Шелестов Максим Евгеньевич.

Контекстные действия закреплены снизу по центру safe area. До трёх семантических основных действий находятся в одном горизонтальном ряду; ширина зависит от подписей и доступного экрана. `⋯` открывает вверх сгруппированный список с внутренней прокруткой и ограниченной высотой. Повторное нажатие и Escape сворачивают список. Нажатие снаружи сворачивает его и поглощается защитным Control.

`×` полностью скрывает панель. Refresh и тики в том же scope её не возвращают. Новое местоположение/набор объектов возвращает контекст; Enter явно показывает скрытую панель без отправки команды, стрелки возвращают её с выбором. Сохранены экземпляры кнопок по ключам, выбор, снимок нажатой команды, проверка актуальности и pending guard I5. Авторитетная обработка команд не менялась.

Обычный HUD больше не создаёт `PlayMiniMap`/`DebugBoard`. Верхние кнопки: **Меню · Планшет · Карта · Счёт · ?**. Убраны только верхние ярлыки События, Путь и Доставка; в планшете игрока остаются События, Обучение и Доставка. Полная карта и M сохранены. Часы/пауза, деньги и объём рюкзака остаются в одной строке; товарные значки уступают место основным показателям, если не помещаются.

Общий футер `TabletPanel`: одна строка `◷ HH:MM:SS · Пауза/Время идёт`, справа переключатель без повторной подписи, область касания 48×44. Убран лишний разделитель, уменьшены промежутки. Делегат паузы прежний. Общие поверхности стали нейтральнее и теплее, зелёные акценты приглушены, границы спокойнее; специальные цвета опасных действий сохранены.

## Проверки

Проверки выполняются существующим драйвером I6-B с одной фазой `hud`, на прежнем compact-valley checkpoint с тремя обычными NPC. Новых экономических прогонов и матриц карт нет. Конечный локальный HUD-прогон `native-7`: **107 проверок, exit 0 за 151.752s / 600s**, строгий Godot log — exit 0, orphan nodes — 0. Обычная сборка и AssemblyAudit — exit 0. [Receipts и исходные хеши](verification/i6c1/README.md). Native проверяет положение/раскрытие, полное скрытие и явное возвращение, Refresh/тики, стабильность Control и выбора, mouse/key/touch, защиту от click-through, единственную отправку настоящих команд PlaceEquipment/Automatic, pending/устаревший payload, RU/EN, 960×440 и 800×360, футер/паузу, сохранённые разделы и M. Проверены invariants, checkpoint round trip и три точных будущих тика с восстановленными обычными контроллерами.

Первоначальные ошибки probe, реальная ошибка ширины popup и последующие целевые исправления не скрыты: [история и receipts](verification/i6c1/README.md). Используются прежние runtime references; после ошибок повторялась только фаза HUD, без экономических матриц. Старые CityExperience probes открывают события/обучение через планшет; OrdinarySetup проверяет roster в полной карте. Проверки команд, сроки и обязательные workflow сохранены.

Обязательный GitHub CI проверяется на конечном HEAD Draft PR; актуальные статусы доступны на [странице проверок ветки](https://github.com/MaksShelest/Delsk/actions?query=branch%3Afeat%2Fvnext-i6c1-hud-context). Окончательные номера запусков и результаты фиксируются в описании PR, чтобы не запускать CI повторно ради записи его собственного SHA в отчёт.
