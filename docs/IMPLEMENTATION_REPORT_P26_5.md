# P26.5: простая 3D-сцена для презентации

Автор: Шелестов Максим Евгеньевич. Дата: 17.10.2026.

Игровые правила не менялись. Сцена рисует уже существующий мир. Числовые работники остаются числами в карточке. P27 и интерфейс второго месяца не начаты.

## Что видно

Godot .NET 4.7.2, главная сцена `Playfield.tscn`, окно 1100×720. Слева наклонная камера и простые фигуры. Справа прежняя карточка P26: пауза, один тик, сохранение, загрузка, RU/EN, работа, поставки и ставки.

Три показа:

- **Экономика** — `baseline-economy`. Белая фигура — человек, три цветные — NPC. Зелёный цилиндр — древесина, жёлтый — зерно. Коричневые клетки — участки, серые — непроходимые.
- **Политика** — `baseline-politics`. У человека сразу есть лесопилка. Клик по ней выбирает предприятие, карточка шлёт обычную команду.
- **Рейс** — `logistics-cycle`. Клиент выполняет тот же префикс команд, что и проверенный цикл, и останавливается на паузе, когда у системы есть `Trip`. Жёлтый ящик — груз на клетке пути. Аргумент `-- --trip` открывает этот показ сразу.

Клик по пустой клетке карты отправляет `MoveTo`, по ресурсу — `Harvest` одной единицы. WASD и стрелки шлют тот же ход. Отказ ядра пишется текстом под кнопками. Сдвиг фигуры между клетками только рисуется и замирает, пока мир на паузе. `--smoke` по-прежнему открывает `PlatformProbe` и не строит эту сцену.

`Presentation.Read` берёт клетки участников, постройки и рейс из `Inspect`. В кадр не входят чужие договоры поддержки и чужие балансы. Карточка человека читает только `Observe`.

## Как показать

Нужен Godot **.NET** 4.7.2, не обычный редактор без C#. Из Rider или редактора открыть `src/Client.Godot` и нажать F5. Либо из корня репозитория, подставив путь к `Godot_*_mono_*_console.exe`:

```powershell
godot --path src/Client.Godot
godot --path src/Client.Godot -- --trip
```

Сначала собрать клиент Debug, если сборка ещё не лежит в `.godot/mono/temp/bin/Debug`:

```powershell
dotnet build src/Client.Godot/Delsk.Client.csproj -c Debug --nologo '-m:1'
```

На показе: снять паузу и дать человеку и NPC пройти несколько клеток; добыть ресурс кликом; в политике выбрать лесопилку и остановить или продолжить работу; нажать **Рейс** и показать жёлтый груз, затем снять паузу и дать ему доехать. Сохранение и загрузка возвращают ту же партию.
