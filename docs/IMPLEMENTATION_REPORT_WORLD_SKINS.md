# Заменяемое оформление мира и персонажей

Автор: Шелестов Максим Евгеньевич. Дата: 2026-10-22.

В Delsk подключены утверждённые уютные модели. Старые процедурные модели сохранены как набор **«Основной»**, новый набор называется **«Дополнительный»** и выбран при первом запуске без `user://appearance.json`.

## Использование

На экране выбора карты или в меню паузы открыть **«Оформление и персонажи»**. Первые две кнопки переключают весь мир и набор персонажей независимо. Можно выбрать тип здания/ресурса/техники и переключить только его. Для выбранного участника доступны список десяти имён и кнопка **«Следующий образ»**; предпросмотр обновляется сразу. Выбор персонажа включает дополнительный набор людей. Переключение общего набора мира сбрасывает индивидуальные переопределения типов.

Настройки сохраняются атомарно в локальный `user://appearance.json`, отдельно от игровых сохранений. Повреждённый JSON или неизвестные значения сбрасываются к допустимым значениям. Отсутствующая модель использует прежнюю процедурную фабрику. При загрузке игрового сохранения остаётся выбранное локальное оформление.

## Модели

- Пять производств, торговая лавка, ратуша с терминалом, грузовик с грузом/без груза и две добывающие машины.
- Шесть состояний смешанного леса: густой/редкий × взрослый/молодой/вырубленный. Стадия следует публичному остатку ресурса: ноль — вырубленный, меньше половины ёмкости — молодой, иначе взрослый. Плотность определяется сравнением ёмкости с максимальной для того же ресурса на карте.
- Сплошные поля пшеницы и свёклы без оград; общий пустой чернозём при исчерпании. Пастбища с одной/двумя коровами без оград.
- Десять образов: Алина, Михаил, Джеймс, Линь Мэй, София, Томас, Елена, Амир, Диего, Нора. Алина и Михаил — славянские образы; Джеймс — темнокожий, Линь Мэй — китаянка; всего шесть светлокожих образов. Имена используются над персонажами, в рейтинге, голосовании и выборе торгового партнёра. Это десять доступных обликов, а не добавление фиктивных участников экономики.
- Исправлены уклоны козырьков кондитерской, пекарни, лавочки и терминала; передний край ниже заднего. Входной козырёк ратуши заменён односкатным. У кондитерской сохранена утопленная торговая ниша с задней стеной.
- Обновлены согласованные SVG: брёвна с округлыми торцами, колосья, сахар и разные иллюстрации производств. Живые планшеты и их привязки сохранены.

Редактируемые сцены находятся в `art/cozy_world_v4/models`. Игровые `ArrayMesh` в `src/Client.Godot/skins/cozy` объединяют детали по материалу: 32 файла, около 2 MB. Две составные демонстрации полей оставлены только в исходниках. Воспроизводимая сборка:

```sh
python3 scripts/build_world_skins.py --godot /path/to/Godot
```

`WorldSkins` выбирает фабрику по настройкам, `PresentationStage` заменяет визуальных потомков существующих движущихся объектов. Повторный кадр без изменения стадии/оформления не пересобирает статическую сцену. Координаты, пути, контроллеры, ID, стоимость, уровни и экономические правила остаются в Core. Общие ресурсы мешей кешируются.

## Границы

Персонажи являются статическими прототипами без скелетной анимации. Исходная ратуша занимает три клетки на арт-макете; в действующей карте каждый скин равномерно вписывается в существующий логический footprint. Расширение территории терминала требует отдельного изменения карты/проходимости. Косметическое переключение не меняет эту геометрию симуляции. Выбор задаётся по типу модели и участнику, не по экземпляру каждого одинакового здания.
