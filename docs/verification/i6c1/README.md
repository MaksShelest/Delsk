# I6-C1: native HUD evidence

Автор: Шелестов Максим Евгеньевич.

Использован прежний `physically-arrived.save.json` из I5/I6-A: compact_valley, человек + 3 обычных NPC, купленная техника физически приехала на законно купленный ресурсный участок. Копия — `prepared.save.json`, SHA-256 — `prepared.sha256`. Новый мир и экономический прогон не создавались. Состояние, тики и команды в снимках настоящие; выборы/подписи моделей относятся к прежней игровой сцене.

Драйвер I6-B расширен одной фазой `hud`; обычная сборка проверяется AssemblyAudit до подключения изолированного `I6BUnifiedProbe`. В ходе прогона источники заморожены, runtime references не меняются. Deadline 600s прежний; строгая проверка Godot log сохранена. Включён существующий `--touch-controls`, поэтому джойстик виден и в широком окне. Linux llvmpipe и синтетический mouse/key/touch ввод не заменяют физическую приёмку устройств.

Пример воспроизведения с установленными .NET/Godot:

```sh
python scripts/check_i6b_ui.py \
  --output work/i6c1/reproduce \
  --godot /path/to/Godot_mono \
  --fixture docs/verification/i6c1/prepared.save.json \
  --case hud
```

Локально использовались готовые обычные runtime references и импорт ресурсов из предыдущего I6-B. После первого импорта правились только C# UI/probe; повторные targeted builds не повторяли экономическую подготовку.

Ровно четыре PNG верхнего уровня: реальная сцена 1100×720 collapsed/expanded, 960×440 landscape и 1100×720 планшет. 800×360 проверяется без дополнительного PNG, только геометрия.

## Сохранённые попытки

- `attempts/1`: обычная сборка/audit/import успешны; новый probe не собрался: неверное имя свойства паузы и nullable bool. Это ошибки тестового кода, исправлены.
- `attempts/2`: переиспользована обычная сборка; HUD probe остановился при обращении к отсутствующему desktop joystick. Исправлены проверка null и включение штатных touch controls.
- `attempts/3`: native обнаружил реальный выход раскрытого меню вправо: минимальная ширина строк плюс scrollbar раздували контейнер. Расчёт ширины исправлен, строки ограничены доступной областью.
- `attempts/4`: геометрия/раскрытие/закрытие успешны; неверное сравнение command tape до и после обычных NPC-тиков. Probe теперь сравнивает непосредственно до/после Enter, сохраняя проверку отсутствия скрытой отправки.
- `attempts/5`: native и строгий log успешны, 104 проверки. На визуальном просмотре выявлено неудачное распределение ширины: пустое место справа при обрезанных подписях. Ширина основных кнопок распределена по содержимому.
- `attempts/6`: native и строгий log успешны, добавлена проверка сохранённых разделов планшета. При финальном просмотре уточнены нижний safe inset и компактное отображение причин отказа основных действий.

Исходные exit codes/тайминги/ошибки сохранены. Повторы ограничены фазой HUD на том же сохранении. Другие карты/NPC-матрицы/экономические исследования локально не запускались. Обязательные GitHub workflows не ослаблялись и выполняют свои штатные проверки.

## Конечный результат

`native-7`: 107 проверок, exit 0, 151.752s / 600s; native-log exit 0, orphan nodes 0. Обычная сборка и AssemblyAudit exit 0. Итоговые receipts — `checks/`, `native.json`, `gate.json`, `inputs.json`. Все четыре PNG относятся к этому же прогону. `hud.input.save.json` — штатная перезапись исходного checkpoint перед фазой.
