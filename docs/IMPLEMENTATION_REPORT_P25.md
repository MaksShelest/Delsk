## Протокол

`scenarios/research-series-p25.json` расширяет протокол P24 до семян 42–51. Мир — `baseline-politics`, 120 тиков. Три живых режима на одном семени и одном горизонте: baseline, hybrid без переговоров, hybrid со структурированными переговорами. Основной показатель зафиксирован до прогонов: базовая стоимость выпуска, сумма собранного и произведённого количества на базовую цену сценария. Победа на выборах в этот показатель не входит. Задержка модели считается отдельно.

Headless-сравнение выключенной модели с baseline на тех же десяти семенах politics не смешивается с paced/Realtime. Replay каждого живого плеча записан и в серию неуспешных ячеек не попал: все 10×3 прогона и их replay завершились успешно.

Модель — локальная `qwen3.5:4b`, digest `d8b0f5e9760cd1682034f292d7ef72ec46f432149be0df7574bf2d6e92e38c04`, Q4_K_M, Apache-2.0.

## Выпуск и поддержка

На каждом из 10 семян baseline и hybrid-communication дали выпуск 5500, 8 предложений и 3 подписи. Парная разница communication−baseline по этим показателям: медиана 0, разброс 0. Миры при этом не совпали ни на одном семени: отказы контроллера у baseline всегда 3, у communication от 2 до 5. Медиана парной разницы отказов −0.5, минимум −1, максимум 2.

Hybrid без переговоров на всех 10 семенах дал выпуск 0, 0 предложений и 0 подписей. Разница communication−hybrid постоянна: выпуск +5500, предложения +8, подписи +3. SD этих разниц равна 0. Планировочная оценка размера выборки для среднего при таком SD равна 1 паре. Это описание постоянного наблюдаемого сдвига, а не доказательство, что модель умеет договариваться: плечо без `politicsEnabled` не предлагает поддержку по построению протокола.

Безработица на финальном тике равна 0 во всех плечах. Поставочных контрактов на этой фикстуре нет. Простой по строкам labor не различается.

## Выборы и модель

В каждой из 30 партий выборы состоялись один раз. Строгого большинства нет ни в одной: победитель отсутствует в 10/10 партий каждого режима. По этому пилоту победителя объявлять нельзя.

Запросов модели: 3 на партию без переговоров и 6 на партию с переговорами. Все ответы `ModelResolved`. Fallback и stale равны 0 на всех семенах. Задержка только по живым ответам: hybrid 30 образцов, p50 1341 мс, p95 1768 мс; hybrid-communication 60 образцов, p50 1265 мс, p95 1537 мс. Эти числа не складываются с выпуском в один рейтинг.

Выключенная модель на headless совпала с baseline по миру на семенах 42–51.

Regression gate `scripts/check_headless.py` завершился с кодом 0: 618/618 тестов, 81 экспорт, 9 replay, 54 сравнения. Счёт — [verification/p25/regression-gate.json](verification/p25/regression-gate.json). Godot smoke и Android device gate в этом прогоне не повторялись.

## Ограничения

Десять пар — пилот. Горизонт 120 тиков politics-фикстуры, не полный месяц и не economy-сценарий. Алгоритмический baseline не выровнен по бюджету запросов модели. Новый запуск той же модели может дать другие ответы; повтор отчёта читает эти выгрузки. Графики парных разниц выпуска — `docs/verification/p25/paired-model-factor.svg` и `paired-communication-factor.svg`.

```powershell
py -3 scripts/analyze_paired_series.py --series artifacts/p25-series --evidence docs/verification/p25
```
