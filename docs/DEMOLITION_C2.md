# C2: безопасный снос

Автор: Шелестов Максим Евгеньевич.25.10.2026, Europe/Samara.

Встаньте у собственного объекта и откройте его карточку. На предприятиях с
оформленным планшетом блок сноса находится под основными сведениями; остальные
объекты используют общую карточку. Расчёт можно посмотреть и через «Моё хозяйство»,
но подтверждение требует присутствия у объекта.

1. Нажмите «Подготовить к сносу». Это отдельное действие, которое не списывает плату
   за снос. На паузе включите время нижним переключателем, чтобы команда выполнилась.
2. Проверьте причины блокировки в «Снос…». Закончите текущую партию, дождитесь рейса,
   выполните связанные поставки и дайте покупателям забрать их товар. Новые задания
   объекта запрещены; уже принятые партии/рейсы/товарные права не удаляются.
3. Посмотрите стоимость, клетки/уровни, фактический возврат и сохраняемые запасы.
   Для сноса удерживайте кнопку подтверждения две секунды. Короткое нажатие,
   отпускание, уход указателя, потеря фокуса и отмена не подтверждают операцию.
4. На паузе подтверждение подготавливает команду; включите время для исполнения.
   При изменении запасов старый расчёт не принимается. Откройте актуальный расчёт.
5. На освобождённой клетке откройте «Хранение на земле · склад». Обычные запасы
   и возвращённые материалы находятся здесь; превышение70 объёма имеет отдельный
   срок1200 активных тиков. Существующие партии излишка сохраняют прежние сроки.
   Освободите место или вручную спасите излишек по правилам [C1](STORAGE_C1.md).

«Отмена» закрывает расчёт и не снимает плату. «Отменить подготовку» разрешает снова
настраивать объект, но автоматически не запускает остановленную работу/маршруты.
Если для завершения обязательства нужно продолжить новые производственные партии,
отмените подготовку и включите производство обычным способом.

Стоимость в монетах: `30 × число клеток + 15 × сумма(уровень клетки − 1)`.
Две клетки L2 стоят90. Возврат каждого товара:
`floor(сумма реально внесённого количества × 6000 / 10000)`.
30 брёвен дают18,3 стали дают1. Денежные вложения, зарплата и энергия не возвращаются.
Оставшиеся сырьё и продукция сохраняются полностью, независимо от процента возврата.

Реальные внесения берутся из сохранённого журнала расхода стройматериалов. Начальное
здание, выданное сценарием без строительства, не создаёт вымышленных оплаченных
материалов для возврата. Его обычные запасы всё равно сохраняются полностью.

Начатую временную стройку/модернизацию склада можно отменить из её карточки:
расчёт → удержание. Уже оплаченные деньги не возвращаются;60% внесённых материалов
возвращаются, остальная часть явно списывается. При отмене модернизации существующий
уровень склада остаётся. Плата рассчитывается для клетки и уровня отменяемого проекта.
До внесения средств и материалов проект в нынешнем Core не создаётся: закрытие
предварительного окна не требует отдельного возврата ещё не списанного имущества.

Земля остаётся владельцу; работники переходят в безработицу, население сохраняется.
Съёмная добывающая техника не является материалами здания и остаётся собственной
техникой. Логистическая машина также сохраняет ID, уровень, вместимость и стоимость;
в «Моё хозяйство» она показана отдельно. Её можно использовать для явных маршрутов
между действующими объектами через прежний редактор маршрутов и прежний экипаж.
Новый автопарк и прикрепление к будущим цехам этой итерацией не добавлены.

C2 доступен и существующим предприятиям пяти прежних карт. Их производственные
рецепты, старое строительство и торговые правила не переводятся в vNext. После
первого сноса появляется ручное хранение на собственной пустой земле. Сохранения
World18/19 читаются без изменения старого хеша; новые сохранения используют World20.

Проверка после bounded restore/build:

```bash
python scripts/check_demolition_c2.py --output artifacts/demolition-c2
python scripts/check_demolition_ui.py --godot /path/to/godot-mono --xvfb /path/to/Xvfb --output artifacts/demolition-ui
```

Полные цеха, отраслевой XP и расширения разных уровней ещё относятся к D. C2 не
добавляет их и не заменяет недоступные стройматериалы бесплатными. Существующие
контроллерные планы/опыт не удаляются. D1 автоматически не начинается.
