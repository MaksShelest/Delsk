# Отчёт P06: общее ядро в Godot и тестовые экспорты

Автор: Шелестов Максим Евгеньевич. Дата: 14.10.2026.

## Результат и граница задачи

Предыдущая документация и реализация P00–P05 перенесены в GitHub. Дерево удалённого коммита `ab3d81aecf3c5892cbdce3be5cf86f26b4fbd03c` совпало с локальным результатом `4a233927258615ac321494f7bfb46a7067fa90e2`; история локальных коммитов сохранена. [PR №1](https://github.com/MaksShelest/Delsk/pull/1) сравнивает реализацию с веткой `docs/architecture-v0.3`. Изначально репозиторий был пустым; после первой записи GitHub автоматически сделал `feat/economic-cycle-p00-p05` веткой по умолчанию. Ветка main не создавалась, PR автоматически не сливались.

P06 реализован как отдельная минимальная Godot .NET сцена. Она получает встроенную фикстуру, подаёт записанные команды через тот же `GameSession` и проверяет хеш после каждого тика. Правила экономики, движение и расчёты остаются в Core; Hosting не зависит от Godot. Клиентский проект имеет собственную solution и не добавлен в `Delsk.sln`, поэтому проверка ядра по-прежнему не требует Godot.

На экране доступны один тик, пуск/пауза и повтор сначала. Это платформенный стенд с записанными командами, а не автономные NPC или готовый игровой интерфейс. Полноценный клиент остаётся P26. Изменений игровых правил нет; SHA-256 спецификации остаётся `b86447e9311ab676538e1edbf7fd217c5a09896c3fc0d5edda7569ae088e9376`.

**Облачная часть P06 выполнена. Проверка на настоящем Android-телефоне остаётся открыта.** Создание APK и искусственные уведомления не означают успешного запуска на устройстве.

## Обнаруженные проблемы и исправления

- Локальная распакованная Godot binary оказалась обрезана: SHA-256 отличался от архива, запрос версии падал. Повторная распаковка восстановила совпадение и запуск.
- Godot возвращал exit 0 при ошибке публикации C#. Добавлен `scripts/verify_platform_probe.py`: он проверяет журнал, отчёт повторения и состав Windows-комплекта. Старый ошибочный экспорт с exit 0 эта проверка отклонила. Допускается только конкретная известная ошибка редактора при завершении `EditorSettings ... shutdown_adb_on_exit`; другие `ERROR:` отклоняются.
- Экспорту нужна solution с именем assembly. Добавлены `Delsk.Client.csproj` и `Delsk.Client.sln` с Debug/ExportDebug/ExportRelease. Экспортные runtime-locks идут в игнорируемый obj, сохраняя обычные lock files Core CI.
- В облаке многопроцессная публикация Godot завершалась неудачно; `DOTNET_PROCESSOR_COUNT=1` позволил выполнить экспорт. Это настройка окружения, не правило игры.
- Android потребовал ETC2/ASTC, icon, платформу 36 и полный JDK. SDK tool archives пришлось нормализовать из вложенного каталога; первоначально доступная Java не содержала javac.
- Новые command-line tools 23.0 не смогли скачать свою дополнительную CLI. Использованы официальные 19.0. Установка NDK 29 остановилась на ошибке архива; native-сборка не заявляется готовой.
- Gradle в этой среде потребовал настройки существующего proxy и системного Java trust store. Настройки остались вне репозитория; проверка TLS не отключалась.
- Первый Windows CI упал из-за разбора `-m:1` PowerShell как двух аргументов. Аргумент заключён в кавычки; следующий CI прошёл. Сбой сохранён как факт, а не успешная проверка.

## Открытый device gate и следующий шаг

На ARM64 телефоне с Android 7.0/API 24 или новее установить тестовый APK, открыть стенд, проверить один тик/пуск/паузу, пройти все 62 тика, свернуть в пути на минуту и убедиться, что за время отсутствия мир не продвинулся. На возврате проверить остановку/продолжение и экранный итог. Сохранить модель телефона, Android, отчёт `user://platform-probe.json` и журнал; при доступном adb копировать через `run-as com.maksshelest.delsk.probe`. Хеш должен совпасть с runner. Отдельно выполнить smoke готового Windows-комплекта. Запуск на устройстве, производительность и GPU пока не измерены.

Следующая небольшая задача кода — **P07**: клетки земли, числовая цена, платная временная бронь 10% сверх последующей покупки, защищённые коридоры и атомарная проверка footprint/стройки/отдельного склада. Все команды проходят Core, UI правил не содержит. Проверить деньги в казну, чужую бронь/землю, включительную границу срока и отсутствие частичного списания материалов. Не добавлять одновременно динамический найм или вторую цепочку. Device gate P06 остаётся видимым до P12/P27; save/load сейчас не реализуется.
