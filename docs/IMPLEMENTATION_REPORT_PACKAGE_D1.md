## Результат

До итерации каждый EnterpriseState имел одну партию/рецепт/группу. C1 и C2 уже
работали и не реализовывались повторно. Теперь явный D1-профиль включает независимые
оснащённые цеха (до5), каждый с собственным рецептом, WIP, реальным числовым штатом,
ставкой и управлением. Общие input/output и деньги остаются конечными; используются
прежние транзакции, трудовой рынок, команды, логистика и подготовка к сносу.

Кривая0/25/45/65/85/100%, полный выходной hold, атомарный расход сырья/оплата,
неоплачиваемый простой, сохранение остановленной партии, фиксированные условия
старта и перенос существующих работников проверяются отдельно. При дефиците
внутри предприятия действует сохраняемый least-recent-start; прежняя ротация
между группами/ролями сохранена.

Оснащение готового места оплачивается один раз деньгами и реальными материалами
из input, занимает60активных тиков и создаёт остановленную линию с нулевым штатом.
Все партии и численности участвуют в C2, публичном капитале/выпуске, инвариантах,
сохранении и replay. Грузовик возит несколько видов продукции, не меняя уже
принятый груз. Алгоритм получает только собственные DTO и пользуется теми же
валидаторами для запуска/обеспечения/переноса/вывоза/оснащения готового места.

UI показывает каждый цех и его актуальное состояние, управление, штат/проценты,
прогресс/ставку партии, установку/срок и общие хранилища. Добавлены RU/EN названия
новых товаров/отраслей, причины отказов и справка. Управление временем прежнее.
Новые игры двух designedmaps/lab presets используют воспроизводимый профиль
`economy.d1-workshops.json`; пять прежних карт и resolved config старых партий
не меняются.

World21 включает новые состояния; limited reader20/19/18 разрешён без D1полей.
Новые null/default поля не пишутся. Реальный старый C2World20 checkpoint794
продолжен до1996: точный прежний final hash
`5b052b874926b59425b98366cfced5eecc3b86e2e864a970f6b5533bf05fec64`
и каждая строка metrics.csv сохранены. Исследовательский workshops.json сравнивается
при save/load/replay; в чужой Observation данные цехов не добавляются.

## Граница результата

Шесть базовых фабрик имеют одно оснащённое место в реальной начальной цене.
Открытие/покупка новых контуров и мест, XP/задания, полноценные стройпроекты,
V2/V3 и импорт стройматериалов остаются D2. Старое одноместное legacy улучшение
не превращается бесплатно в многоместный vNextкорпус. Многоместные сценарии явно
подготовлены (3/6физических клеток); оснащение, персонал, сырьё, payroll и услуги
в них настоящие. Достижение второй ступени натуральным развитием обычной партии
этим не доказывается. Начальная стройка пока требует прежних материалов в рюкзаке;
полные комплекты/их доступность остаются зависимостью следующего этапа.

Windows/Android hardware, длительная производительность на большой карте и
оптимальная самостоятельная стратегия всех шести отраслей не проверены.
Реальная LLM для D1 не требовалась и не запускалась.
