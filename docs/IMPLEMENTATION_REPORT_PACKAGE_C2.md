# C2: подготовка, безопасный снос и возврат материалов

Автор: Шелестов Максим Евгеньевич.25.10.2026, Europe/Samara.

База9220b4c, слитый PR61/C1. В начале дерево было чистым, результат C1 проверен
по коду и истории. Использованы существующие Inventory/EconomyTransaction,
VolumeWork, construction journal, Delivery/Freight, workforce, UI/Save/Replay.
Ветка `feat/vnext-package-c2`; D1 не начинался.

## Реализовано

- Собственный предварительный расчёт по занимаемым клеткам:3000minor за клетку,
  +1500minor за каждый уровень выше первого. Две клетки L2 стоят90монет.
- Возврат floor6000bp от суммы фактических внесений каждого товара. Источник —
  ConstructionMaterialConsumed в полном журнале, а не нынешний рецепт. 30wood→18,
 3steel→1. Стартовый бесплатный объект не порождает вымышленных материальных вложений.
- PrepareDemolition останавливает новые партии, обычные назначения и новые обещания
  объекта. Незавершённая партия может закончиться; уже принятые рейсы, груз, входящие
  обязательства, рыночная выдача и товарные holds сохраняются. Open buy-offer
  освобождает только ещё не подписанные бюджет/заявки. Безопасный снос блокируется
  до завершения/освобождения связанных операций с понятными причинами.
- Действие сноса отдельно от подготовки: fresh quote token, проверка доступа,
  местоположения, ресурсов и holds. UI: расчёт → непрерывное удержание2сек. Отпускание,
  уход указателя, потеря фокуса, короткое нажатие и отмена не подтверждают снос.
  Старый расчёт при изменении запасов отклоняется без платы.
- Нормальные запасы сохраняются полностью, материалы распределяются стабильно по
  своим освобождённым клеткам. Вместимость70, превышение — отдельный C1 overflow1200
  активных тиков. Старые lot ID/сроки сохраняются. Только оставшийся излишек может
  потеряться по сроку; вручную спасти его можно обычными командами C1.
- Земля остаётся владельцу. Workers→unemployed атомарно сохраняет население и
  исторические голоса. Геометрия здания освобождается; повторная стройка проверена.
- Retired Building/Enterprise и пустые старые inventory identities сохраняются
  для исторических договоров/выдач и техники, но исчезают из действующих зданий,
  производства, капитала построек и препятствий. Архив включён в canonical hash;
  повреждённый уровень архивного объекта отвергается при загрузке.
- Съёмная техника не превращается повторно в стройматериал. Логистическая машина
  сохраняет ID/уровень/кузов/ценность и может выполнить новый явный маршрут после
  сноса и повторной застройки. «Моё хозяйство» показывает сохранённую машину с прежним
  RouteEditor. Второго транспортного исполнителя или нового автопарка не добавлено.
- Отмена существующей временной стройки/модернизации сохраняет уже понесённую оплату,
  возвращает60% только её фактических материалов, применяет плату за снос проекта
  и при необходимости overflow. Существующий уровень при отмене модернизации остаётся.
- ConstructionRecovered отделён от Produced/Harvested, учтён в физическом балансе,
  запасах и demand periods. Возврат не увеличивает валовый выпуск; остаток вложений
  имеет явный discard event. Нормальная вместимость/товарные резервы не ослаблены.
- C2 работает на существующих предприятиях пяти прежних карт. До явного C2 действия
  их hash/ID-поток прежние. После сноса появляется ground/overflow, config.Storage
  не подменяется, старые production/build/delivery правила не переводятся молча в C1.
- World20 с ограниченным чтением World18/19 без новых состояний; старое C1 сохранение
  загружено с прежним exact hash. Session2/Envelope2 и Rules production-recipes-1
  прежние. Research export дополнен demolition.json; состав возврата и token не
  раскрываются через public events. Контроллеры не получили WorldState/чужих DTO.

## Границы и ограничения

- Текущие здания имеют один общий Level: для стоимости он применяется к каждой
  занимаемой клетке, а quote/receipt сохраняют клетки отдельно. Разнородные ступени
  будущих расширений и цехов не добавлены до D.
- Фактически существующие временные стройки — склады C1. Мгновенное legacy
  строительство не получает выдуманной стадии отмены; будущие производственные
  строительные проекты относятся к D.
- Отраслевой XP ещё не представлен отдельным состоянием текущего Core. C2 не удаляет
  имеющиеся контроллерные планы/опыт и не реализует XP/D1 ради формальной отметки.
- Новые карты по-прежнему ждут полные цепочки стройматериалов/импорт D. C2 их не
  подменяет и не выдаёт бесплатно. Снос действующих старых предприятий доступен.
- Windows/Android device, большой долгий мир и аппаратная производительность не
  проверены. Linux software/native gates не заменяют аппаратную приёмку.
- Подготовка не списывает чужие права и не расторгает подписанный договор бесплатно.
  Если WIP/обязательство не может завершиться, нужно восстановить его условия,
  отменить подготовку либо дождаться существующей процедуры исполнения/истечения.
