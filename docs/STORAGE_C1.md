# C1: земля, склады и временный излишек

Автор: Шелестов Максим Евгеньевич.25.10.2026.

Новые партии на small_river и large_districts используют
`config/vnext/economy.c1-storage.json`. Пять прежних карт сохраняют economy-v6.
Старые сохранения используют собственный resolved config: загрузка не переводит
партию в другой баланс и не меняет вместимость существующих объектов.

На своей пустой клетке откройте «Хранение на земле · склад». Укажите количество
и выложите/заберите товар. Вместимость70 — сумма количества×объём, общая для
разных товаров. Это только перенос между личным запасом и клеткой: земля не
подходит для торговли, назначения автоматических маршрутов или приёма контракта.
Чужие запасы/излишки в этот планшет не попадают.

Для склада положите строительные материалы **на клетку**, затем нажмите
«Построить склад». Для улучшений материалы должны лежать в обычном запасе склада.
Строительство списывает доступные материалы и деньги один раз; участник может
уйти. Вместимость увеличится после окончания работ. Отмена/снос относится к C2.

| Уровень | Общий объём | Дополнительная цена, монеты | Материалы | Активные тики |
|---|---:|---:|---|---:|
| I | 200 | 100 | доски10 | 60 |
| II | 300 | 250 | доски20, сталь4 | 120 |
| III | 400 | 600 | балки6, бетон10 | 180 |

Важная зависимость: полный промышленный контент и импорт vNext ещё не исполняются
в supported A2/C1. Поэтому естественное получение всех этих материалов на новых
картах пока не обеспечено. C1 не подменяет их древесиной и не выдаёт бесплатно.
Подготовленный сценарий `scenarios/vnext/storage-c1-fixture.json` содержит явные
тестовые источники стройматериалов и увеличенный рюкзак. Он проверяет операции,
но не доказывает доступность всей строительной цепочки в обычной партии.

Уже принятая поставка разгружается и оплачивается даже при заполненном получателе.
Только не поместившаяся часть становится отдельными партиями излишка: например,
210/200. Срок каждой партии —1200 **активных** тиков от её собственного поступления.
Следующий груз не переносит старый срок. Предупреждение появляется сразу,
повторные события — за600/120 тиков; планшет показывает товар, остаток и срок.
Существующие обычные резервы места/товара сохраняются.

Освободите обычное место: излишек автоматически займёт его, сначала с ближайшим
сроком. Либо у склада выберите количество и «Спасти излишек»: начнётся физический
перенос в личный запас. До перевода в обычный запас излишек нельзя продать,
обещать политической сделке или использовать в производстве. После срока
теряется только оставшаяся рискованная часть. Новые заказы на переполненный объект
не принимаются; обычная выкладка/производство не создают такого исключения.

Планшет открывается на паузе. Действие можно подготовить и включить время нижним
переключателем. Меню, справка, потеря фокуса и другие существующие причины паузы
останавливают как стройку, так и срок излишка. Сохранение включает активные работы,
партии, прогресс переноса и его резервы; «Продолжить» восстанавливает их.

Проверка без Godot после bounded build:

```bash
python scripts/check_storage_c1.py --output artifacts/storage-c1
```

Нативная проверка в изолированной копии, Linux/Xvfb:

```bash
python scripts/check_storage_ui.py --godot /path/to/godot-mono --xvfb /path/to/Xvfb --output artifacts/storage-native
```

Это C1. Возврат стройматериалов при сносе, подготовка освобождения клетки,
промышленные цеха, импорт, новые машины и перевозочные услуги здесь не добавлены.
