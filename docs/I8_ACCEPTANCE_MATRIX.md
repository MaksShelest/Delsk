## Обычный сквозной сценарий

| Шаги задания | Степень покрытия |
|---|---|
| 1–4. Запуск, новая партия, карта, сложность, NPC, специализация | Реальный Godot проверяет меню и два мира; Research.Runner проверяет поддерживаемые комбинации через `OrdinaryNewGame` |
| 5–13. Поддержка → участок → доставка → стройка → найм → сырьё → выпуск → продажа → операционный результат | Обе карты × четыре направления в управляемых партиях с пустым стартом. Отдельно NPC, полностью за счёт реальных действий. Остаток, прибыль и капитализация считаются отдельно |
| 14–19. Расширение, рецепт, техника, логистика, дороги, контракты | Штатные регрессии и подготовленные миры. Единого естественного пути до всех шести шагов пока нет |
| 20. Несколько предприятий | Тест общей технологии и стоимости второго корпуса. Естественное устойчивое управление двумя предприятиями открыто |
| 21. Сохранить и продолжить | Реальный клиент I7: продолжение во втором процессе. Исследовательское продолжение проверяется по хешам отдельно |
| 22. Политическая система | Текущие NPC доходят до выборов и подают голоса. Ручная приёмка голосования, обязательств и финала остаётся открытой |
