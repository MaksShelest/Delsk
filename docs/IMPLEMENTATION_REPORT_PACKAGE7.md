## Реализовано

**P30.** Склад — открытая площадка с погрузочным проходом на реальном anchor, ограждением по фактическим Walls/Footprint и ограниченным числом штабелей по физическим остаткам. Место, зарезервированное для будущего приёма, не превращается в товар. Разные товары имеют разные формы/цвета; смешанный запас сохраняется. Только собственный склад получает эти данные, чужой помечается неизвестным, без утечки запасов/вместимости из Inspect. Визуальные меши не добавляют физические коллайдеры или новые правила доступа; прежние blocked cells остаются авторитетными. Серый блок на клетке склада заменён ограждением, чтобы не скрывать товар.

Существующие L1/L2 производств и двух типов добывающей техники различаются силуэтом. Лавочка сохраняет фиолетовый акцент. Придуманных уровней, новых производств и полосок процессов над зданиями нет. Статическая геометрия и запасы имеют раздельные ключи/кеши. Один склад ограничен24 штабелями/4 слоями; неизменный кадр не создаёт новые модели. Форма PresentationFrame не относится к World checkpoint и не меняет его формат.

**P57.** Короткие RU/EN-реплики строятся из публичных состоявшихся событий строительства, торговли, добычи и изменений публичного текущего штата. Не читаются controller goals, чужие условия или будущие состояния. Событие начала добычи описывает наблюдаемый сбор сырья, не раскрывает тайный план поиска. Нет неподтверждённого «бот мешает». Максимум2 реплики, срок3.2 активных секунд, пауза между репликами участника8 секунд; важная реплика может заменить менее важную. Подписи расположены на разных высотах, скрываются при планшете/help/menu/паузе/focus loss. Варианты выбирает отдельный косметический hash публичной идентичности события, без World PRNG/LLM.

Звуки кнопки, добычи/завершения, строительства, сделки и важного уведомления имеют отдельный ограничитель и общий pool из2 players. Большой batch событий схлопывается, без очереди сотен звуков. Есть тихое синтетическое окружение и необязательная музыка (по умолчанию0%). Три громкости и выключение реплик доступны в меню/выборе партии и сохраняются в user://feedback.cfg, вне экономики/checkpoint. Пауза/focus приостанавливают loop и прекращают игровые эффекты; возобновление не воспроизводит накопленную историю. UI clicks доступны в меню. Все WAV процедурно созданы проектом, источник/CC0 в `audio/LICENSE.txt`, генератор сохранён. Проверено исполнение Godot через Dummy driver, не качество звучания на динамиках устройства.

**Пекарня.** BakeryTablet.tscn/SVG/theme из архива подключены к настоящим PlayerView и прежним HouseholdObjectCard actions/access через общий ProductionTabletPresenter. Это минимальное обобщение presenter лесопилки, без второго набора экономических команд. Исходник архива и оригинальный README сохранены. Demo.gd/project.godot/примерные запасы/цены не импортированы. Nunito из двух архивов побайтно одинаков: используется уже поставленный шрифт/OFL без дублирования файлов.

Отображаются реальные рецепт/партия, grain/bread stocks/reserves/volume, текущая численность/ставка и ожидаемое изменение, местные материалы улучшения (доски), грузовик и независимые production/inbound/outbound. Help/Close/Time остаются общими. На карточке<980 — читаемое компактное представление; при другом или многокомпонентном рецепте применяется полная прежняя карточка вместо неверной картинки. Источники/получатели/настройки используют прежний RouteEditor и валидаторы. Лесопилка сохраняет тот же набор действий.
