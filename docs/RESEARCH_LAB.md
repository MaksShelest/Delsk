# Локальная исследовательская лаборатория P58

Автор: Шелестов Максим Евгеньевич.

Python3.10+ и установленный .NET10; браузер любой современный. Playwright нужен только автоматическому UI-тесту. Это отдельный исследовательский интерфейс, без Godot/3D, не часть обычной или Developer-игры. Единственная симуляция — прежний Research.Runner. Результаты содержат полную приватную историю: не публикуйте папку как общедоступный сайт.

Из корня репозитория после bounded restore/build:

```sh
python3 scripts/research_lab.py --output artifacts/lab
# Открыть напечатанный http://127.0.0.1:8765/
# Без браузера, тот же план и та же очередь:
python3 scripts/research_lab.py --output artifacts/paired --plan docs/research/package8-negotiations.json --run
```

Выберите seeds, повторы, тики и режим. JSON-редактор задаёт базовый scenario/economy/controllers, список факторов, composition и modelConfig. Допустимые факторы перечисляет UI; каждый получает values либо включительный целый range `{start,stop,step}`. Для Linux/headless profiling добавьте `profile:true` (только algorithmic): Step stages/CPU/память/encode/decode записываются отдельно от мира. Максимум6 факторов,32 значения/фактор,10000 ячеек,10000 тиков/прогон,500 повторов. CLI JSON поддерживает uint64 seed; UI безопасно ограничивает ввод2^53−1, не округляет большие seeds молча. Вариант композиции перечисляет каждого существующего NPC ровно один раз с actorId/preferredInput; количество участников задаётся сценарием и его controller-конфигурацией.

Все комбинации проходят настоящие валидаторы C# **до постановки**. Сначала копируются разобранные входы, затем валидируются именно копии; изменение исходного файла после постановки не меняет опыт. Для каждой комбинации отдельные economy/controllers, хеши в queue.json; изменение snapshot отвергается. Глобальный config/economy.json не редактируется. Неизвестные/повторные поля, несовместимые режимы, неверные диапазоны/числа/состав отклоняются. Свои JSON-файлы размещайте внутри репозитория или рабочей папки лаборатории.

`npc.negotiationsEnabled=false` выключает только переговорный протокол NPC. Торговля/публичные оферты/исполнение обязательств/политика остаются; покупка поддержки использует существующий прямой ProposeSupport вместо ProposeTrade. Это не выключатель прав Core/человека. Null/отсутствие поля сохраняет прежнюю политику и её сериализацию. Для гибрида нужен явный реальный loopback modelConfig: fake здесь недоступен. Валидность config не доказывает доступность/качество модели; фактический runtime/fallback пишется обычным runner.

Старт/продолжение обрабатывают очередь последовательно. **Пауза между прогонами**: активный bounded прогон завершается, следующий не начинается. Это не заморозка процесса/частичного экономического тика. Журнал атомарно сохраняется, один host.lock запрещает двух владельцев. После перезапуска очередь остановлена; running становится interrupted, завершённые не повторяются. «Повторить ошибки» выдаёт новый attempt/output, не перезаписывает старый. Ctrl+C прекращает приём UI, активный ограниченный job заканчивается. После аварийного завершения ОС старый attempt остаётся исследовательским артефактом, не засчитывается автоматически. Каждый job имеет hard timeout1..900с (по умолчанию180); ошибки содержат ссылку на stdout/stderr.

В папке серии: исходный plan, валидированные inputs, проверки, каждый `runs/<job>/<attempt>`, исходные runner JSON/CSV/JSONL, series.json и summary.json/csv. Интерфейс выгружает все исходные файлы, показывает прогресс/ошибки/папку и агрегаты выбранных серий. Парные разности right−left сопоставляются по seed/repeat при одинаковом scenario snapshot; **при анализе нужно дополнительно сверить economy/controllers/model и объявленные факторы**. Сравнение разных трудностей не является само по себе доказательством превосходства Hard. Повтор детерминированного seed не увеличивает число независимых наблюдений; independentSeeds указано отдельно.

Проверка с настоящим Chromium/runner, без HTTP-fake симуляции:

```sh
python3 scripts/run_check.py --name lab-ui --timeout 220 -- python3 scripts/check_research_lab.py --output artifacts/lab-ui
python3 scripts/run_check.py --name lab-unit --timeout 45 -- python3 -m unittest discover -s tests/Research.Lab -v
```

UI-gate отклоняет противоречивую комбинацию, запускает/останавливает/продолжает две ячейки, скачивает CSV, проверяет token access, CLI-equivalence и полный экспорт save/load/replay. Loopback Host/Origin+непубличный токен предотвращают запросы чужих страниц; интерфейс не предназначен для сетевого multi-user hosting.
