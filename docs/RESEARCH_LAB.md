# Исследовательская лаборатория Delsk

Автор: Шелестов Максим Евгеньевич. Обновлено 22.10.2026 (Europe/Samara).

Лаборатория работает **самостоятельно в браузере**, без открытой игры, Debug-окна,
Godot или LLM. Она запускает прежний Research.Runner, сохраняет каждый опыт и
сравнивает результаты. Нужна полная папка исходников Delsk; одного игрового EXE
недостаточно. Исследовательские файлы не включаются в сборку игры.

## Первый запуск в Windows

1. Обновите исходники до версии с этой доработкой.
2. Нужны **Python 3.10+** (включая Python Launcher) и **.NET SDK 10.0.401** —
   версия из `global.json`. Если `py -3 --version` уже показывает Python 3.14,
   переустанавливать его не нужно. Нужен именно .NET **SDK**, не только Runtime.
3. В корне Delsk дважды щёлкните **ResearchLab.cmd**. Не файл в `scripts`, не EXE игры.
4. Запускатель сам проверит SDK, выполнит bounded restore/build runner и откроет
   браузер. При первом запуске нужны Интернет для NuGet и несколько минут ожидания.
   Следующие сборки инкрементальные. Ничего через pip/npm устанавливать не требуется.
5. Оставьте окно запуска открытым, пока исследование работает.

Запускатель сначала использует `py -3`, затем `python`, если launcher отсутствует.
Пути с пробелами поддерживаются. Выбранный свободный порт исключает конфликт с
другим локальным сервисом. Повторный запуск ResearchLab.cmd открывает ту же
работающую лабораторию, без второй очереди и повторной сборки.

Если браузер не открылся, скопируйте напечатанный адрес `http://127.0.0.1:<порт>/`.
Открывайте адрес именно с 127.0.0.1, а не заменяйте его на localhost.

Linux/macOS: `sh ResearchLab.sh` из папки исходников; те же SDK/Python и обычный браузер.
Windows double-click/macOS hardware не проверяются автоматически облачным Linux gate.

## Первое исследование — три действия

1. Оставьте **«Быстрая проверка · 1 прогон»** и нажмите **«Начать исследование»**.
   Это 120 тиков, seed 42, алгоритмы без модели. JSON редактировать не нужно.
2. Дождитесь **«Готово: 1 / 1»**. Показатели появятся автоматически в разделе 3:
   оценка капитала, выпуск, занятость и просрочки. Нулевой выпуск в короткой
   проверке возможен — она проверяет работу инструмента, а не качество баланса.
3. Рядом с серией нажмите **«Скачать серию ZIP»**. Внутри план, валидированные
   входы, исходные JSON/CSV/JSONL, логи, попытки и сводки. Дождитесь завершения
   активного прогона перед ZIP; при длинной серии можно поставить очередь на паузу.

## Исследовать и сравнить

- **Базовое исследование**: 600 тиков × seed 42,43,44, 3 прогона.
- **Сравнить сложности**: Easy/Medium/Hard × те же 3 seed, 9 прогонов.
- **Сравнить переговоры**: on/off × те же 3 seed, 6 прогонов. Отсутствие
  переговорных событий не доказывает, что механизм не влияет на игру.
- Выберите одну из трёх карт, измените тики и seed при необходимости.
- Откройте **«Изменяемые параметры»**: выберите фактор, введите значения через
  запятую и нажмите «Добавить фактор». Повторное добавление заменяет этот фактор;
  крестик убирает его. Все сочетания факторов проверяются до появления в очереди.
- Пример: «Население», значения `100, 200` и три seed дадут 6 опытов.
  Значения денег/зарплат в параметрах — **сотые монеты**: 3000 означает 30 монет.
- Обычные показатели результата в UI переведены в монеты. Исходные CSV/JSON
  сохраняют прежние единицы. Сводка CSV пригодна для Excel.
- Отметьте нужные серии флажками и нажмите **«Сравнить выбранные серии»**.
  Для честного парного сравнения сценарий/настройки должны совпадать кроме
  объявленных факторов. Пары сопоставляются по seed/repeat. Среднее/медиана,
  диапазон и число независимых seed не заменяют содержательную проверку баланса.
- Повтор одного алгоритмического seed — точная реплика, а не новая независимая
  выборка. Короткая серия не доказывает превосходство Hard. Операционный денежный
  результат — не начисленная чистая прибыль с амортизацией и оценкой запасов.

«Дополнительно» сохраняет полный JSON-редактор: economy/controllers, composition,
диапазоны start/stop/step включительно, profile и модель. Семена/тики/повторы/режим
берутся из полей над редактором. Модель по умолчанию выключена. Гибрид требует
явного реального loopback modelConfig и работающего Ollama с установленной моделью.
Fake не предлагается; проверка конфигурации не доказывает успешный inference.

## Пауза, закрытие и восстановление

**Пауза действует между прогонами**: активный bounded опыт заканчивается, следующий
не начинается. Она не замораживает частичный экономический тик. «Продолжить»
запускает ожидающие задания; «Начать исследование» добавляет новую серию и
запускает также ранее ожидающие задания общей очереди.

Кнопка **«Завершить лабораторию»** останавливает приём новых опытов и ждёт окончания
активного. Когда окно запуска завершится, его можно закрыть. Закрытие только вкладки
браузера не останавливает очередь. Ctrl+C также запрашивает остановку между опытами.

Результаты по умолчанию находятся в **`artifacts/lab`**, путь виден в интерфейсе.
После нового запуска очередь находится на паузе; завершённые задания не повторяются.
Нажмите «Продолжить» для оставшихся. После аварии running становится interrupted;
«Повторить ошибки / прерванные» создаёт новую попытку, сохраняя прежние файлы.
Не удаляйте host.lock ради второго процесса — блокировка ОС защищает одну очередь.

Не меняйте проверенные inputs уже поставленного опыта: SHA-проверка отклонит его.
Для новых параметров создайте новую серию. Старые результаты содержат версии/commit;
после изменения правил проекта сопоставляйте совместимость отдельно.

## Если запуск не удался

- **Python not found**: проверьте `py -3 --version`; установите Python с Launcher.
  Запуск через ResearchLab.cmd не требует работающего псевдонима `python` из Store.
- **Требуется SDK**: установите указанную в сообщении версию из `global.json`;
  другие SDK удалять не нужно. Godot устанавливать ради исследований не требуется.
- **Restore/build failed или timeout**: см. `artifacts/lab/startup/lab-restore.*`
  и `lab-build.*`; проверьте Интернет/NuGet и повторите запуск. Ошибка сборки
  не открывает UI со старым runner. Шаги имеют timeout по 180 секунд.
- **Лаборатория уже использует папку**: дождитесь завершения первоначальной
  подготовки. Если прежний host уже запущен, ResearchLab.cmd откроет его страницу.
- **Ошибка опыта**: в очереди доступны «Ошибки runner», «Вывод runner» и JSON
  проверки. Исправьте причину и явно повторите ошибочные задания. Для каждого
  опыта timeout 1..900 секунд (по умолчанию 180); старые попытки не перезаписываются.
- **Нет связи в браузере**: повторно откройте ResearchLab.cmd и используйте новую
  вкладку с актуальным портом/токеном. После перезапуска старая вкладка устаревает.

## CLI и проверки

Старые команды совместимы; output теперь необязателен:

```bat
py -3 scripts/research_lab.py --prepare --open-browser --port 0
py -3 scripts/research_lab.py --prepare --output artifacts/paired --plan docs/research/package8-negotiations.json --run
```

Без `--prepare` предполагается уже собранный Release runner. В CLI JSON разрешён
полный uint64 seed; браузер ограничен безопасными целыми JavaScript 0..2^53−1.
`--run` не открывает HTTP-сервер. Несколько независимых лабораторий должны иметь
разные `--output`; первый host владеет своей очередью до завершения активной работы.

Проверки из корня репозитория:

```sh
python3 scripts/run_check.py --name lab-unit --timeout 60 -- python3 -m unittest discover -s tests/Research.Lab -v
python3 scripts/run_check.py --name lab-launcher --timeout 150 -- python3 scripts/check_research_lab_startup.py --output artifacts/lab-launcher
python3 scripts/run_check.py --name lab-ui --timeout 240 -- python3 scripts/check_research_lab.py --output artifacts/lab-ui
```

Playwright/Chromium нужны только UI gate, не пользователю лаборатории. Gate проверяет
настоящие browser→runner, отказ невалидному плану, паузу/продолжение, preset одним
нажатием, ZIP, узкое окно, CSV, токен/Host/Origin, CLI-equivalence, save/load/replay.
Launcher gate проверяет подготовку, повторный запуск, блокировку, Unicode/пробелы,
завершение и валидность всех 12 сочетаний готовых presets/карт через C#.

Сервер слушает только loopback. Host/Origin и непубличный токен защищают API,
скачивание исходных файлов, ZIP и завершение. Health сообщает только идентичность
процесса для повторного открытия. Полная история содержит приватные данные:
не публикуйте результаты как общедоступный сайт. Core/контроллеры/формат сохранений
не менялись; это доработка оболочки P58, не закрытие открытых P59/P60 hardware/model gates.
