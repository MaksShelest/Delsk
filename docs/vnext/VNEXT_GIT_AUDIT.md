## Чего нельзя начинать заново

P28–P50 выполнены в исторически утверждённом составе. В частности, P48/P49 не означали восемь видов сырья/новую металлургию: тогда был выбран пищевой вариант C. Нельзя переписать эти номера так, будто новые требования уже были их старым содержанием. Многокомпонентные рецепты, физические маршруты, рынок, планшеты, Developer и лаборатория расширяются, а не создаются второй раз.

Не все пункты до P60 приняты целиком: P53, P56, P59, P60 имеют открытые gates. Подробный текущий статус P28–P60 — в соседнем плане. Исторические числа 897 ordinary/903 Developer/37 Python относятся к отчёту PR52; свежий запуск полного набора в этой задаче не заявлен.

## Открытая приёмка прежнего объёма

1. Hard efficacy: ранее были отрицательные paired-результаты; наличие planner не доказательство преимущества.
2. Актуальная реальная LLM в обычной игре: HTTP fixture/503/старый P23 не заменяют её.
3. Длинный баланс/ROI и активность переговорного фактора: подготовленные fixtures и 600 тиков не закрывают вопрос.
4. Полная история: прежний 5000-тиковый профиль дал save58,6 MB / decode15,7 s / peak4,95 GB; новая запись кадров добавляет свой объём. Проблема не снята.
5. Реальные Windows EXE/Android-device, lifecycle/input/safe areas/FPS/audio. Windows CI/экспорт не равны устройству.

P61–P80 сохраняются как новый план поверх готовой основы: единый отраслевой XP/задания, параллельные цехи, расширения и эффективные версии рецептов, 60% сноса/ground inventory/склады, overflow, 34 товара/23 базовых рецепта, автопарк, дороги и счета, услуги с явным принятием/несколькими рейсами, меню 3–10 ботов, две дополнительные карты, слои и новая калибровка.
