## Важные границы

Это пакет проектирования, а не исходники реализованной игры. Новые JSON требуют адаптации к актуальному загрузчику Delsk. Git сверён на dfd6b8e (PR52); статусы исправлены по коду, отчётам и GitHub. Динамические прогоны экономики, C# tests, Godot, Windows/Android и реальная LLM в этой документационной задаче не запускались. Проверка маржи не доказывает достижение целевых сроков развития.

Исторические документы репозитория сохраняются; новую спецификацию подключать отдельным файлом. Сначала проверить текущие AGENTS, HEAD, рабочее дерево и уже выполненные PR. На проверенной основе4c61179 A1 уже слит PR55; A2 реализован, B1/B2 ещё не начаты. Прежние P28–P60 не начинать повторно без сверки. P61–P80 — новый объём; каждое изменение состояния сразу включает snapshot/validation/replay.

Новые документы хранят принятые механики отдельно от изменяемого B1. Для изменения каждого числового параметра повторное согласование не требуется: версия профиля, измерения и объяснение изменения обязательны.

Актуальный аудит: [VNEXT_GIT_AUDIT.md](VNEXT_GIT_AUDIT.md). P28–P50 уже готовы в прежнем объёме; следующий новый пакет — A (P61 и каталог P63), а не повтор пакета1.

Для следующих отдельных реализаций: [guide A](PACKAGE_A_IMPLEMENTATION_GUIDE.md), [guide B](PACKAGE_B_IMPLEMENTATION_GUIDE.md) и три полных промпта: **[A2](CODEX_PACKAGE_A2_PROMPT.md) → [B1](CODEX_PACKAGE_B1_PROMPT.md) → [B2](CODEX_PACKAGE_B2_PROMPT.md)**. Каждый запуск — после фактического результата предыдущего, отдельный PR и остановка. Исторический [промпт A1](CODEX_PACKAGE_A1_PROMPT.md) сохраняется, повторять выполненное не нужно.
