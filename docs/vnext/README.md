## Важные границы

Это пакет проектирования, а не исходники реализованной игры. Новые JSON требуют адаптации к актуальному загрузчику Delsk. Git сверён на dfd6b8e (PR52); статусы исправлены по коду, отчётам и GitHub. Динамические прогоны экономики, C# tests, Godot, Windows/Android и реальная LLM в этой документационной задаче не запускались. Проверка маржи не доказывает достижение целевых сроков развития.

Исторические документы репозитория сохраняются; новую спецификацию подключать отдельным файлом. Сначала проверить текущие AGENTS, HEAD, рабочее дерево и уже выполненные PR. На проверенной основе45fae36 A1/A2/B1/B2 включены; C1/C2/D1/D2/D3 подготовлены, ещё не реализованы. Прежние P28–P60 не начинать повторно без сверки. P61–P80 — новый объём; каждое изменение состояния сразу включает snapshot/validation/replay.

Новые документы хранят принятые механики отдельно от изменяемого B1. Для изменения каждого числового параметра повторное согласование не требуется: версия профиля, измерения и объяснение изменения обязательны.

Актуальный аудит: [VNEXT_GIT_AUDIT.md](VNEXT_GIT_AUDIT.md). P28–P50 уже готовы в прежнем объёме; после A/B следующий новый пакет — C, а не повтор пакета1.

Для следующих отдельных реализаций: **[C1](CODEX_PACKAGE_C1_PROMPT.md) → [C2](CODEX_PACKAGE_C2_PROMPT.md) → [D1](CODEX_PACKAGE_D1_PROMPT.md) → [D2](CODEX_PACKAGE_D2_PROMPT.md) → [D3](CODEX_PACKAGE_D3_PROMPT.md)** и обязательный [guide C/D](PACKAGE_CD_IMPLEMENTATION_GUIDE.md). Исторические guide A/B и промпты A2/B1/B2 сохраняются. Каждый запуск — после фактического результата предыдущего, отдельный PR и остановка. Исторический [промпт A1](CODEX_PACKAGE_A1_PROMPT.md) сохраняется, повторять выполненное не нужно.
